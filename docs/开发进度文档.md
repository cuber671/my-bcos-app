# FISCO BCOS 基础服务模块开发进度文档

## 开发准则

### 实施过程准则
1. **JSON对象 = 独立功能单元**：每个JSON任务对象代表一个独立的功能单元
2. **完成一个任务，提交核心逻辑描述，等待用户确认后再进行下一个**
3. **开发内容需参考tasks目录和docs目录下的相关文档**
4. **不同类要存储在对应的文件目录下面**（参考docs/项目目录结构说明.md和docs/项目模块目录结构说明.md）
5. **用户下一个任务**

###测试修改后再进行 开发流程
1. 查看tasks/基础服务模块.json任务列表
2. 阅读相关文档（docs/目录）
3. 制定实施计划（写入.claude/plans/humming-questing-galaxy.md）
4. 用户批准后开始开发
5. 创建/修改对应文件
6. 编译验证（mvn compile -q）
7. 更新tasks/基础服务模块.json中的is_completed字段
8. 用户测试
9. 循环到步骤1

- `SecurityConfig.java` - 注册限流拦截器

### 使用示例
```java
// 查询接口限流10 QPS
@RateLimit(qps = 10, key = "query")
@GetMapping("/api/query")
public Result<?> query(...) { ... }

// 写入接口限流2 QPS
@RateLimit(qps = 2, key = "write")
@PostMapping("/api/write")
public Result<?> write(...) { ... }
```

## BAS_014 熔断配置（已完成）

### 新增文件
- `src/main/java/com/fisco/app/Common/Annotation/CircuitProtection.java` - 熔断保护注解
- `src/main/java/com/fisco/app/Common/Aspect/CircuitBreakerAspect.java` - 熔断切面

### 修改文件
- `pom.xml` - 添加Resilience4j依赖.yml` - 添加
- `application熔断配置
- `AuthorizationTestController.java` - 添加熔断测试端点

### 使用示例
```java
// 区块链调用熔断保护
@CircuitProtection(name = "blockchain", fallbackMethod = "fallback")
@PostMapping("/blockchain/call")
public Result<?> callContract(...) { ... }

// 兜底方法
public Result<?> fallback(...) {
    return Result.error(40004, "Service temporarily unavailable");
}
```

### 配置参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| failureRateThreshold | 50 | 失败率阈值，超过此值触发熔断 |
| waitDurationInOpenState | 30000 | 熔断持续时间（毫秒） |
| slidingWindowSize | 100 | 滑动窗口大小 |
| minimumNumberOfCalls | 10 | 最小调用次数 |
